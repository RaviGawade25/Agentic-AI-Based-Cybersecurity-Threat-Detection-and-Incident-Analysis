# Security Policy

## Scope

This project is a defensive educational prototype. It does not provide
automated containment, account changes, exploitation, or production-grade
security monitoring.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue. Use the
repository's private GitHub security advisory reporting flow when available.
If that flow is unavailable, contact the repository maintainer privately
through the contact method listed on the maintainer's GitHub profile.

Include a clear description, affected files or versions, reproduction steps
using synthetic data, impact assessment, and a suggested mitigation when
possible. Do not include credentials, private logs, or other sensitive data.

## Supported versions

Only the latest version on the default branch is actively maintained. This
project does not promise security updates for older snapshots or forks.

## Safe handling

Run the Windows collector only with the permissions required to read the
Security log. Treat uploaded logs and generated reports as sensitive
operational data, and remove them from shared environments when no longer
needed.
